# Production rollout for emspaced.com (Phases 1 + 2)

This repo (`jh27.life`) is a static copy used for testing. The real site **emspaced.com** runs **WordPress + Elementor + Yoast behind Cloudflare**.
Everything in Phases 1 and 2 is either generated by `tools/geo_optimize.py` or listed below as a one-off setting.


`llms.txt`, `llms-full.txt`, `ai.txt`, `robots.txt`, `sitemap.xml`.

## 1. Security headers (Cloudflare) - Technical score

GitHub Pages (jh27.life) **cannot** send custom headers, so the audit on the test domain will still flag HSTS.
On emspaced.com, set them in Cloudflare:

**A. HSTS** - Cloudflare dashboard -> SSL/TLS -> Edge Certificates -> *HTTP Strict Transport Security (HSTS)* -> Enable
- Max-Age: 12 months, Include subdomains: On, Preload: On (only after confirming all subdomains serve HTTPS), No-Sniff: On
- Also turn on *Always Use HTTPS*.

**B. Other headers** - Rules -> Transform Rules -> *Modify Response Header* -> Create rule
- When: `Hostname equals emspaced.com` (or all incoming requests)
- Then **Set static**:

| Header | Value |
| --- | --- |
| `X-Content-Type-Options` | `nosniff` |
| `X-Frame-Options` | `SAMEORIGIN` |
| `Referrer-Policy` | `strict-origin-when-cross-origin` |
| `Permissions-Policy` | `camera=(), microphone=(), geolocation=(), interest-cohort=()` |
| `Content-Security-Policy` | `upgrade-insecure-requests; frame-ancestors 'self'` |
| `Cross-Origin-Opener-Policy` | `same-origin-allow-popups` |

> [!NOTE]
> A full script-allowlist CSP would break Elementor, Chaty and Google Fonts. The policy above is safe and
> is what most auditors check for. Verify at https://securityheaders.com/?q=emspaced.com (target: A).

Fallback if Cloudflare is not used - add to the top of `.htaccess`:

```apache
<IfModule mod_headers.c>
  Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains; preload"
  Header always set X-Content-Type-Options "nosniff"
  Header always set X-Frame-Options "SAMEORIGIN"
  Header always set Referrer-Policy "strict-origin-when-cross-origin"
  Header always set Permissions-Policy "camera=(), microphone=(), geolocation=(), interest-cohort=()"
  Header always set Content-Security-Policy "upgrade-insecure-requests; frame-ancestors 'self'"
</IfModule>
```

## 5. Structured data (Yoast) - Schema score

1. **Yoast -> Settings -> Site representation**
   - Organization name `Emspaced`, logo, and **Other profiles**: Facebook, X, LinkedIn and **Instagram** (`https://www.instagram.com/emspacedmy/` was missing).
2. **Author** - Users -> *Emspaced Admin* -> change *Display name publicly as* to a real person
   (preferred: name + job title + LinkedIn in *Contact info* / Yoast profile fields), or at minimum `Emspaced Editorial Team`.
   Do the same for the visible byline on posts.
3. **Organization extras** (contactPoint, knowsAbout, areaServed, location links) - add with a small snippet
   (Code Snippets plugin) so it matches the static build:

